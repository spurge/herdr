# herdr-app config

My [Herdr](https://herdr.dev) setup. Only my own files are tracked.

- `layouts/my-main.json`: Herdr's `main` layout with PR and issue panels added (`my-main.svg` is its settings preview)
- `mods/prs/`: PR panel for GitHub (`gh`) and Gitea (`tea`)
- `mods/issues/`: issue panel for GitHub (`gh`) and Gitea (`tea`)
- `mods/my-tabs/`: tab bar with PRs and Issues buttons
- `mods/my-files/`: Files panel that renders markdown
- `themes/`: six solarpunk themes, three for day and three for night
- `settings.json`, `keys.json`: settings and key bindings
